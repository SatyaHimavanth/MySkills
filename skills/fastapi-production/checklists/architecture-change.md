# Architecture Change Checklist

- [ ] Existing implementation and consumers inspected
- [ ] Existing project conventions identified
- [ ] Shared contract reviewed
- [ ] Local/prod differences reviewed
- [ ] Security implications reviewed
- [ ] Database/migration impact reviewed
- [ ] API compatibility reviewed
- [ ] Concurrency/distributed-state impact reviewed
- [ ] Observability impact reviewed
- [ ] Tests updated
- [ ] Rollback/forward-fix path considered
- [ ] ADR/documentation updated when the decision is durable
